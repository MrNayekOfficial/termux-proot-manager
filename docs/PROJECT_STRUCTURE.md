### Profiles

Dynamically generated by `refresh_profile_launchers()`:
- One script per installed distro
- Located in `profiles/` directory
- Simple one-liners that call main script

### User Files (Not Tracked)

These are created at runtime:

```
~/.termux-superproot/config           # Optional user config
~/.termux-superproot/bin/             # Generated launcher scripts
~/.termux-superproot/logs/            # Execution logs
~/.solve_problrm.conf                 # ADB configuration
~/.solve_problrm.log                  # Recovery activity log
```

## Key Code Locations

### termux-superproot.sh

**Distro Management:**
- `install_distro()` - Install proot distro
- `installed_distros()` - List installed distros
- `is_distro_installed()` - Check if distro exists

**Desktop Environment:**
- `setup_desktop_in_distro()` - Install XFCE + tools
- `install_audio_support()` - Audio package installation

**X11 & Display:**
- `start_termux_x11()` - Start X11 server
- `wait_for_x11()` - Poll for X11 readiness
- `start_vnc_fallback()` - VNC as fallback display

**Process Management:**
- `stop_related_processes()` - Kill related processes
- `safe_kill()` - Fallback process killer

**Profiles:**
- `refresh_profile_launchers()` - Generate per-distro wrappers
- `create_profile_launcher()` - Single distro wrapper

**Sessions:**
- `start_full_session()` - Orchestrate full startup
- `recover_session()` - Recovery workflow
- `login_distro()` - Simple distro login

### solve_problrm.sh

**ADB Operations:**
- `require_adb()` - Verify adb availability
- `pair_wireless_debugging()` - ADB pairing flow
- `connect_wireless_debugging()` - ADB connect

**Device Analysis:**
- `check_device_compatibility()` - Device checks
- `collect_device_snapshot()` - Capture device state
- `append_snapshot()` - Log device data

**Remediation:**
- `run_fix_profile()` - Apply Android settings fixes
- `retry_step()` - Retry wrapper with logging
- `recover_flow()` - Multi-step recovery
- `auto_fix_flow()` - One-command fix

**Configuration:**
- `load_config()` - Load ADB settings
- `save_config()` - Persist settings
- `show_status()` - Display current config

## Build & Distribution

### Creating a Release

```bash
# Ensure all files are present
ls -la *.sh problem.txt README*.md LICENSE CHANGELOG.md

# Verify scripts
bash -n termux-superproot.sh
bash -n solve_problrm.sh

# Create archive
tar -czf termux-proot-manager-v1.0.0.tar.gz \
  termux-superproot.sh \
  solve_problrm.sh \
  profiles/ \
  problem.txt \
  README.md \
  LICENSE \
  CHANGELOG.md \
  CONTRIBUTING.md \
  SECURITY.md \
  docs/

# Create GitHub release with asset
# Upload .tar.gz to Releases page
```
